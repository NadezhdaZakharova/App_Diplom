# App_Diplom — подробное описание проекта

## 1. Назначение и концепция

`App_Diplom` — Android-приложение для организации тренировочного процесса в двух ролях:

- **ученик** — формирует/выполняет собственные тренировки и работает с тренировками от тренера;
- **тренер** — собирает тренировочный план и передает его ученику в формате JSON.

Приложение ориентировано на offline-first подход:

- основное хранение — локальная БД `Room`;
- UI построен на `Jetpack Compose`;
- данные синхронно отражаются через `Flow/StateFlow`;
- геймификация и статистика пересчитываются локально.

## 2. Полный функционал

## 2.1 Роли и режимы

- Первый экран предлагает выбор режима: **ученик** / **тренер**.
- Режим можно переключать в процессе работы из верхней панели.
- Для ученика доступны разделы тренировок и наград, для тренера — фокус на создании планов.

## 2.2 Банк упражнений

- Каждое упражнение содержит:
  - название;
  - описание;
  - значение повторений по умолчанию.
- Добавление выполняется через форму на экране тренировок.
- Банк используется как источник для формирования планов.

## 2.3 Формирование тренировки тренером

- Тренер добавляет упражнения из банка в план «для ученика».
- План отображается как список с порядком и повторениями.
- Для удаления элемента предусмотрена кнопка удаления у каждой позиции.
- Кнопка **«Сформировать тренировку»** генерирует JSON-представление плана.

## 2.4 Экспорт и отправка тренировки

- После генерации JSON доступен блок с предпросмотром.
- В блоке есть две действия:
  - **Копировать JSON** (в буфер обмена);
  - **Отправить** (`Intent.ACTION_SEND`, `text/plain`) в любое подходящее приложение.
- Кнопки расположены рядом в одной строке (левая/правая).

## 2.5 Импорт тренировки учеником

- Ученик вставляет JSON в поле «JSON тренировки от тренера».
- По кнопке «Импортировать» происходит валидация и загрузка плана.
- Статус операции показывается текстовым сообщением (успех/ошибка).

## 2.6 Сохранение упражнений из тренерского плана в личный банк

- В разделе ученика «От тренера» у каждого импортированного упражнения есть кнопка:
  - **«Сохранить в мой банк»**.
- Нажатие сохраняет упражнение в личный банк упражнений ученика:
  - название берется из плана;
  - повторения берутся из `plannedReps`;
  - описание ставится как «Импортировано из тренировки тренера».

## 2.7 Сессия тренировки (таймер)

- При запуске тренировки открывается режим сессии:
  - отображается текущее упражнение;
  - показывается обратный отсчет;
  - есть прогресс выполнения по упражнениям.
- Добавлена пауза/возобновление:
  - кнопка переключается между **«Пауза»** и **«Возобновить отсчёт»**.
- Добавлен контролируемый выход из режима:
  - кнопка **«Закрыть режим тренировки»**;
  - диалог подтверждения:
    - заголовок: `Точно выйти?`
    - текст: `Прогресс тренировки будет сброшен`
    - действия: `Выйти` / `Отмена`.

## 2.8 Награды, статистика и геймификация

- Отслеживаются шаги и дневная активность.
- Поддерживаются:
  - XP и уровень;
  - streak (серии);
  - weekly challenge;
  - набор достижений.
- Для ученика доступны карточки наград и агрегированные показатели.
- Пересчет выполняется локально (включая фоновый пересчет через Worker).

## 3. Архитектура

Приложение построено по слоистой схеме с MVVM.

### 3.1 UI слой (`ui`)

- Compose-экраны и компоненты.
- `MainViewModel` как центральная точка обработки действий.
- `MainUiState` как единый источник состояния экрана.
- Навигация через `NavigationSuiteScaffold` и внутреннее состояние, без `NavHost`.

### 3.2 Domain слой (`domain`)

- Доменные модели и интерфейсы репозиториев.
- Бизнес-правила геймификации (`GamificationEngine` и вспомогательные классы).
- Use case сценарии (`AddStepsUseCase`, `BootstrapGameUseCase`).

### 3.3 Data слой (`data`)

- `Room` БД (`DiplomDatabase`), DAO (`DiplomDao`) и entities.
- Репозитории:
  - `ActivityRepositoryImpl`;
  - `GamificationRepositoryImpl`;
  - `TrainingRepositoryImpl`.
- JSON импорт/экспорт тренировки реализован в `TrainingRepositoryImpl`.

### 3.4 Infrastructure (`app`, `di`, `work`, `worker`)

- `MainActivity` — entry point, lifecycle интеграция шагомера.
- `DiplomApplication` + `di/*` — DI через Hilt.
- `DailyWorkScheduler` и `DailyRecalculateWorker` — фоновый пересчет.

## 4. Технологический стек

## 4.1 Платформа и язык

- **Kotlin**
- **Android SDK** (min/target в Gradle-конфиге проекта)

## 4.2 UI

- **Jetpack Compose**
- **Material 3**
- **NavigationSuiteScaffold**

## 4.3 Архитектура и асинхронность

- **MVVM**
- **Kotlin Coroutines**
- **Flow / StateFlow**

## 4.4 Хранение и сериализация

- **Room (SQLite)**
- **org.json** для обмена тренировками в JSON

## 4.5 DI и фоновые задачи

- **Hilt (Dagger)**
- **WorkManager**

## 4.6 Интеграция с Android API

- **Intents** для внешней отправки (`ACTION_SEND`) сформированной тренировки.

## 4.7 Тесты

- **JUnit** (unit)
- **AndroidX Test** (instrumented)

---

## 5. Текущие границы и актуальные ограничения

- Входящие deep links/share-target обработчики отключены из актуального scope.
- Отправка тренировки наружу (`ACTION_SEND`) сохранена.
- Сетевой слой (`Retrofit`) и облачная синхронизация пока не реализованы.
- Хранение данных полностью локальное, с `fallbackToDestructiveMigration`.

---

## 6. Преимущества текущей версии

- Четкое разделение ответственности (`ui/domain/data`).
- Прозрачный пользовательский сценарий «тренер -> ученик».
- Современный стек Android (Compose + Hilt + Room + Flow).
- Функциональный режим тренировки с паузой и безопасным выходом.
- Возможность ученику переиспользовать тренерские упражнения в личном банке.
